RoboRooster #32819 — 3D Robot CAD Models Directory
==================================================

Upload your robot .GLB (recommended, single self-contained binary with colors/materials) or .OBJ (+ optional .MTL) here:

1. For the 2026/2027 BIOBUZZ robot:
   - /assets/models/Scrimmage_bot.glb  (or /assets/models/biobuzz-bot.glb / .obj)

2. For the 2025/2026 DECODE robot:
   - /assets/models/decode-bot.glb  (or /assets/models/decode-bot.obj + .mtl)

Notes:
- Any valid .glb, .gltf, or .obj file placed in this folder without "decode" in its filename is automatically detected for the BIOBUZZ 3D viewer.
- Exporting from Onshape, Autodesk Fusion, or Blender as .GLB (under ~15-20 MB) preserves colors/materials and loads quickly on phones.
